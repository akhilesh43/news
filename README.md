
📰 News App

A modern News Application that allows users to stay updated with daily news, watch news videos, search articles, bookmark important news, and switch between light and dark modes.

This app is designed to provide a clean and user-friendly interface for reading and managing news efficiently.

✨ Features

📰 Daily News Updates – Browse the latest news from various categories.

🔍 Search News – Quickly find news articles by keywords.

🔖 Bookmark News – Save articles to read later.

🎥 News Videos – Watch video news directly in the app.

🌙 Dark / Light Mode – Toggle between themes for better user experience.

⚡ Fast & Simple UI – Smooth and responsive interface.
